## The claim it must end on

A scanner that assumes dark bars on a light ground fails on an inverted
code. Dark mode turned a boarding pass into light bars on black; switching
the phone to light mode fixed a scan that was about to cost a flight.
Polarity is a contract between the code and the reader, not a detail.
