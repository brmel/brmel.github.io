# Content packages

Queued pillar articles for the Tech pipeline, in the order to write them.
One package is one pillar article: written once for ibraverse in EN, FR and
AR with the `new-article` command, then cut five ways — the site article, a
LinkedIn carousel, a LinkedIn text post, an Instagram carousel, and an
Instagram reel or story with a Facebook retelling.

Pillars, weighted 4/3/2/1 across ten posts: Machine Vision Up Close ·
Engineering Judgment · Field Notes · Built in Public. Every package names
the measurable claim the piece must end on (the Bridge Rule in AGENTS.md)
and the source material that already exists — a package never starts from
research that has not been done.

When a package ships, delete its file here.
