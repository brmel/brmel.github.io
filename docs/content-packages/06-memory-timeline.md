## The claim it must end on

A production process ran out of virtual memory while Task Manager showed
one calm number. Tracing virtual memory by type over time — MemoryTracer
against VMMap, same figures — showed which band grows and never comes
back down. The piece ends on the diagnosis rule: the leak is the band
that never returns, and you can only see it on a timeline.
