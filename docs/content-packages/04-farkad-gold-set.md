## The claim it must end on

Farkad's router is scored on a gold set before any model change ships:
100% routing and per-field exact match on 15 sentences in English, French,
Arabic, Spanish and mixed languages. The piece ends on the transfer: the
evaluation discipline from the day job, run unchanged on a side project —
an agent you cannot grade is an agent you cannot ship.
