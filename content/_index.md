I develop the 2D and 3D vision algorithms in the Aurora Imaging Library, Zebra's
machine vision SDK: the geometry, calibration and measurement tools that run on
factory floors. I take machine learning from prototype to production inside that
library, evaluate deep learning models for object and text detection, and
optimise the algorithms to run on Zebra's smart cameras, where memory and
processing power are limited. Modern C++ on Windows and Linux, seven years on
the same codebase: Matrox Imaging first, then Zebra after the acquisition.
