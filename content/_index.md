I am a software engineer. I work in C++ on image processing, machine vision and
robotics.

At work I build software that runs inside industrial factories: tested,
maintained, optimised and validated before it ships.

On my own time I keep learning new things, program for fun, and build real
projects end to end. What I enjoy most is the edge cases: the input nobody
planned for, the one that only fails on the fourth run. The write-ups here
include what did not work.
