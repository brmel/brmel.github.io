I've written production C++ for seven years, on Windows and Linux: Matrox
Imaging first, then Zebra after the acquisition. I developed the 2D and 3D
vision algorithms in the Aurora Imaging Library, Zebra's machine vision SDK: the
geometry, calibration and measurement tools that run on factory floors. Inside
that library I took machine learning from prototype to production, evaluated
deep learning models for object and text detection, and optimised the
algorithms to run on Zebra's smart cameras, where memory and processing power
are limited. Today I also build generative AI: agentic workflows, RAG, and the
evaluations that decide when an agent is ready to ship.
