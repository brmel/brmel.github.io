This site is static HTML generated by Hugo 0.168 and served by GitHub Pages. I
own every template: there is no theme underneath, just 59 template files, one
stylesheet and a handful of small scripts. Here is how it fits together, and the
checks that keep it that way.

## Pages

Every page is plain HTML plus one stylesheet. The home page is about 5.5 KB of
compressed HTML, and the stylesheet about 8.7 KB compressed, cached after the
first page. The stylesheet is sixteen numbered files concatenated in order, so
the file number is the cascade, and every colour is defined in one tokens file.

## Three languages

The site is in English, French and Arabic, which reads right to left. The
structural pages exist in all three. An article I haven't translated still
appears in the French and Arabic lists, labelled "in English", and the language
switch on that article takes you to the section in your language. The CSS uses
logical properties only, so the Arabic layout mirrors without a second
stylesheet; a check fails the build on `left` or `right`.

## Maths, code and images

Equations are written in LaTeX and converted to MathML when the site builds, so
pages ship no maths library. Code is highlighted at build time too. Images go
through Hugo's pipeline: list thumbnails are cropped to 16:9 in WebP, the
profile photo is AVIF with a WebP fallback, and every image has a width, a
height and alt text.

## JavaScript

Scripts run only where a page can't work without them: the theme toggle, the
code copy button, search, the resume's video dialog, the PariData controls, the
frame that embeds a data report, and analytics. Search is 40 lines with no
library. It downloads one index (the title, description and first 2,000
characters of each page) and keeps the pages that contain every word you type,
ignoring accents.

## Third parties

A Content-Security-Policy blocks every request to another domain except Google
Analytics, which loads once the page is idle. Fonts are self-hosted.

## Thirteen checks

`./scripts/check.sh` builds the site and runs thirteen gates, and CI runs the
same script on every pull request; a push to `main` deploys only if it passes.
They check orphaned files, the PariData ledger, the social card of every page,
colour contrast (every text colour clears 4.5:1 on both backgrounds, in both
themes), the CSS (no colour outside the tokens file, no unused class), page
structure (one `h1`, a skip link, sized images), that every page is listed in
its section, links, direction safety, script selectors, HTML validity with the
Nu HTML Checker, search metadata, and the paths named in the docs.

## Budgets

On a simulated mid-range phone, Lighthouse has to score at least 98 for
performance and 100 for accessibility, best practices and SEO, with the largest
element painted within 1.5 seconds, no layout shift and no blocking time.

## For machines

[/llms.txt](/llms.txt) and [/llms-full.txt](/llms-full.txt) describe the site
for language models, and every Tech and Adventures page is also served as
