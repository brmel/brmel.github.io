{{- /* reportframe — embed a self-contained HTML report from assets/ as a full-bleed, auto-resizing iframe. The report is pulled through Hugo Pipes (resources.Get) and published via .RelPermalink, so it ships natively with the site. Usage: a reportframe shortcode with src set to the path under assets/ (e.g. src="reports/hydro-quebec-outage.html") and a title. The iframe is isolated, so the report's own Plotly/Leaflet/Bootstrap CSS+JS render exactly as generated with zero clash against the site. */ -}} {{- $src := .Get "src" -}} {{- $r := resources.Get $src -}} {{- with $r -}} {{- else -}} {{- warnf "reportframe: resource %q not found in the page bundle" $src -}} {{- end -}}
